【使用说明】

1. 股东名册，又称股东名录/股东花名册/股东登记册，属于公司成立后的法定文件，本模板的应用场景：公司类的创业投资者在设立一家有限责任公司后依法制定股东名册并存放于公司备查。

2. 本名册由公司根据公司股东信息制作，请确保与公司章程、股东协议对外信息一致，用作对外证明时建议由法定代表人签名并加盖公司公章。

3. 鉴于我国官方没有发布具有指导效力的此类名册范本，本模板系笔者根据2024年7月1日最新修订的《公司法》等现有法律规定与多年从业经验编写，可供公司类创业者在创业之初起草或审查此类文本时予以框架参考。

4. 本模板不属于针对任何特定人或特定公司的正式法律文本，若对本模板有不解之处，建议与笔者先行交流，否则因理解有误或使用不当造成的不利后果，笔者特此声明免责。

【填写指引】

股东信息

（一）股东类型
分类维度股东类型指引说明
1.按法律身份自然人股东指中国公民。 • 填写要点：使用身份证件上的姓名，并准确填写身份证号码。
法人股东指依法成立的公司、企业、事业单位、社会团体等组织。如“XX有限公司”、“XX合伙企业”。 • 填写要点：必须使用工商登记的全称，证件类型选择“营业执照”，并填写统一社会信用代码。
非法人组织股东指个人独资企业、合伙企业等。 • 填写要点：使用其法定名称及对应的证件号码。
2.按出资来源国资股东指国有独资企业、国有控股企业等。 • 填写要点：股权转让需遵循严格的审批和评估程序。
内资股东指中国自然人、中国公司或其他中国组织。 • 填写要点：准确登记其中国身份证明或注册文件，并注意其投资领域是否受限。
外资股东/港澳台股东（参照外资管理）指外国自然人、外国公司或其他外国组织以及参照外资管理的港澳台主体。 • 填写要点：准确登记其身份证明或注册文件，并注意其投资领域是否受限。
（二）股东证照

1. 自然人股东的身份证件类型

身份证件类型适用股东指引说明
中华人民共和国居民身份证中国大陆公民（含归侨）最常用、最标准的个人身份证件，填写时确保信息与身份证原件完全一致，号码为18位。
中华人民共和国护照 （含港澳护照）中国华侨（含港澳华侨）华侨指拥有中国国籍、在国外长期定居没有内地户口，但未加入外国国籍的中国公民。
港澳护照/ 港澳居民内地居住证/ 港澳居民来往内地通行证 （回乡证）香港特别行政区居民/ 澳门特别行政区居民回乡证是港澳居民作为内资公司股东的标准合法证件，格式通常以字母开头（如H/M），后接8位或9位数字。 港澳居民内地居住证逐渐成为有效的登记证件，它拥有18位号码格式与居民身份证相同，便于系统录入和管理，但在使用时建议与市场监管部门确认其接受度。 香港居民使用中华人民共和国香港特别行政区护照，澳门居民使用中华人民共和国澳门特别行政区护照，港澳护照均系中国政府签发的、证明其中国公民身份的官方证件，体现“一个中国”原则，证明持有者的中国公民身份，与内地居民使用的“中华人民共和国护照”性质一致。
台湾居民大陆居住证/ 台湾居民来往大陆通行证 （台胞证）台湾地区居民台胞证是台湾居民在大陆设立公司、成为股东的有效身份证明。 台湾居民大陆居住证逐渐成为有效的登记证件，它拥有18位号码格式与居民身份证相同，便于系统录入和管理，但在使用时建议与市场监管部门确认其接受度。
外籍护照/ 中华人民共和国外国人永久居留身份证外国自然人中华人民共和国外国人永久居留身份证，俗称“中国绿卡”或“五星卡”，是国家移民管理局对符合条件的外国人批准在华永久居留后发放的法定身份证件，有效期5年或10年，在中国境内可单独作为身份证明使用，功能与居民身份证类似。 护照是所有外国自然人股东的唯一通用证件，填写时需准确填写护照上的外文姓名全称、护照号码、国籍，请务必核对护照有效期。

2. 法人股东的注册执照类型

股东类型指引说明注册执照类型
公司制企业法人依据《公司法》设立，承担有限责任，是最常见的法人股东类型。《营业执照》
非公司制企业法人依据《企业法人登记管理条例》等设立，如未改制的全民所有制、集体所有制企业。《营业执照》
事业单位法人由国家或社会力量举办，从事教育、科技、文化、卫生等活动的社会服务组织。《事业单位法人证书》
社会团体法人由中国公民自愿组成，为实现会员共同意愿，按照其章程开展活动的非营利性组织，如行业协会、学会、联合会。《社会团体法人登记证书》
基金会法人利用自然人、法人或者其他组织捐赠的财产，以从事公益事业为目的的非营利性法人。《基金会法人登记证书》
宗教活动场所法人符合《宗教事务条例》规定条件，依法办理法人登记的宗教活动场所。《宗教活动场所法人登记证书》

3. 非法人组织股东的注册执照类型

股东类型指引说明注册执照类型
个人独资企业根据《个人独资企业法》设立的个人独资企业。《营业执照》
合伙企业包括普通合伙、特殊普通合伙、有限合伙。《营业执照》
不具有法人资格的专业服务机构如律师事务所、会计师事务所等。《律师事务所执业许可证》/《营业执照》
其他非法人组织如依法领取我国营业执照的中外合作经营企业、外资企业；法人分支机构；乡镇、街道、村办企业等。《营业执照》或相关登记证件

4. 外资股东的注册执照类型

外资股东类型指引说明身份证件/注册执照的类型
外国公司（企业）在境外注册的法人实体所在国（地区）的注册登记证书、公司成立证明等主体资格证明。 • 填写要点：依据其合法成立地法律规定的注册证明文件准确填写其注册编号、公司名称（外文原名）和注册地址。该文件通常需经当地公证、中国驻当地使领馆认证，并提供中文翻译件。
外国合伙企业在境外注册的合伙组织
外国其他组织在境外注册的其他类型组织
外国自然人外籍个人投资者护照或其他国际身份证件
港澳台企业在香港、澳门、台湾地区注册的实体港澳台地区的注册登记证书及当地公证机构的公证文件。
港澳台自然人香港、澳门永久性居民或台湾地区居民港澳居民居住证、往来内地通行证；台湾居民居住证、台湾居民往来大陆通行证
（三）股东地址
股东类型地址类型指引说明
1.自然人股东身份证件登记住址• 法律身份依据：这是股东法定的住所地址，具有最高证明效力。 • 法律文书送达：在极端情况下（如无法通过其他方式联系），法院可能以此地址作为司法文书的送达地址。
当前实际住址/有效通讯地址• 确保有效沟通：应精确到门牌号，用于寄送分红支票、股东会通知、公司年报等日常重要文件，确保股东能实际收到。 • 操作建议：可在地址栏后注明“（通讯地址）”，或单独设立“通讯地址”列。
2.法人股东/非法人组织股东注册执照登记住所地• 法定住所：这是其在法律上被确认的“住所”，是所有法律文书的核心送达地。 • 一致性要求：必须与其《营业执照》等登记证书上的地址完全一致。
主要办事机构所在地/有效通讯地址• 确保有效沟通：应精确到门牌号，用于寄送分红支票、股东会通知、公司年报等日常重要文件，确保股东能实际收到。 • 操作建议：可在地址栏后注明“（通讯地址）”，或单独设立“通讯地址”列。
（四）股东联系方式
联系途径指引说明
手机号码股东本人（自然人股东）或指定联系人（法人股东与非法人组织股东）的常用手机号，用于紧急事务、会议提醒、日常快速沟通。
电子邮箱股东常用且能稳定接收邮件的电子邮箱，法人股东与非法人组织股东建议使用公司邮箱或主流公共邮箱。作为法律上最重要的通讯渠道之一，用于发送正式的股东会通知、会议材料、财务报告、电子版分配红利通知等。
固定电话法人股东与非法人组织股东应填写其办公室总机或指定部门的电话，格式上应当包含区号。作为备用联系方式，在无法通过手机联系时使用。
授权联系人自然人股东直接填写其本人的手机、邮箱和地址。 法人股东与非法人组织股东必须填写其授权联系人的详细信息（姓名、部门、职务、手机、邮箱）
（五）股东收款账户
账户要素指引说明
账户名称款项必须来自股东本人名下的账户，公司应核对打款人信息与股东名册、工商登记信息是否一致。自然人股东应当填写其本人姓名，法人股东或非法人组织股东则填其法定名称。
账号准确填写股东指定的银行账号，数字务必清晰、无误，避免使用易混淆的字体。
开户行写明银行全称并具体到账户开立的分支行名称。
账户类型可根据需要注明是个人账户或公司账户（对公户）。
币种如果涉及多币种交易，建议注明账户的币种。

二、出资信息

（一）出资认缴情况
认缴要素指引说明
认缴出资金额指股东承诺向公司投入的资金总额，应严格按照公司章程中的约定填写，一般以人民币元为单位，但外商投资企业可以外币表示。
认缴出资时间指股东承诺最终缴足出资的日期，同样依据公司章程的约定填写，需具体到届满的年月日。 如果股东的出资是分期缴纳应当简要说明，例如“分两期缴纳，首期100万已于X年X月X日实缴”。
认缴出资比例指股东的认缴出资额占公司注册资本的百分比，是股东行使权利（如分红、表决）的常见比例。 计算公式： （股东认缴出资额 ÷ 公司注册资本） × 100%。
（二）出资方式
出资方式指引说明填写示例
货币最常用、最简单的出资方式，资金必须存入公司开立的银行账户，并备注“出资款”，否则容易与借款混淆。• 标准填写：货币 或 现金 • 示例：股东以人民币100万元出资。
实物• 实物指机器设备、原材料、产品等有形财产。 • 土地使用权指以国有土地使用权或集体建设用地使用权出资。 • 必须进行评估作价核实财产价值，不得高估或低估。 • 需要办理权属转移手续（如交付/登记过户到公司名下）。 • 股权/债权的出资较为复杂，需要符合特定法律规定。 • 非货币出资必须注明评估机构、评估报告编号及财产权属转移的办理情况（如“已办理专利过户登记”）。• 标准填写：实物 • 为求明确可写：机械设备、原材料、车辆、办公设备等。 • 示例：股东以一套评估作价50万元的生产设备出资。
知识产权• 标准填写：知识产权 • 为求明确可写：专利权、商标专用权、著作权（版权）、非专利技术等。 • 示例：股东以其一项发明专利出资，评估价为200万元。
土地使用权• 标准填写：土地使用权 • 示例：股东以其拥有的一块工业用地的使用权作价500万元出资。
股权/债权• 标准填写：股权 或 债权 • 示例：股东以其持有的另一家公司的股权出资。
其他财产指法律法规允许的、可以用货币估价并可以依法转让的其他财产。• 标准填写：其他财产 或 具体说明，如 域名、数据资产 等。
（三）出资期限
填写要素法律含义指引说明
最终出资日期指股东缴足其全部认缴出资额的最终截止日期。• 必须是一个明确的日期，不能是时间段，禁止使用 “长期””、“无固定期限”、“根据公司需要通知” 等模糊表述，这些写法因违反法律的强制性规定而无效。 - 对于2024年7月1日之后新设立的有限责任公司，股东必须在公司成立之日起5年内缴足全部出资。 - 对于在2024年6月30日之前已经成立的公司（存量公司），如果其章程中约定的出资期限超过了5年，有3年过渡期（至2027年6月30日） 来逐步调整。 • 示例：2030年12月31日
分期出资计划  (如适用)如果股东计划分多次缴纳出资，需要明确每期出资额和该期的截止日期。• 每期都应有明确的金额和日期。 • 示例：首期：50万元，2025年6月30日前；二期：50万元，2028年12月31日前
（四）出资实缴情况
记录要素指引说明
实缴出资金额指股东单次实际缴纳的金额，是对“认缴出资额”的部分或全部履行。 根据《企业信息公示暂行条例》，实缴信息形成之日起20个工作日内应完成公示。
实缴出资日期指该笔出资款实际到达公司银行账户或财产权属转移至公司名下的具体日期。 记录关键辅助信息，如第几期出资、非货币资产的评估价、实缴凭证编号（如银行回单编号）等。
实缴出资比例指股东的实缴出资额占公司注册资本的百分比，根据《公司法》规定，股东按照实缴的出资比例分取红利。 计算公式： （股东实缴出资额 ÷ 公司注册资本） × 100%。
实缴出资凭证货币出资：银行收款凭证（电子回单、转账支票存根）是唯一有效证据。款项必须备注“投资款”并存入公司官方账户。 非货币出资：必须提供资产评估报告和财产权转移证明（如专利证书变更、房产过户登记完成证明）。
（五）出资证明书编号
编号组成部分指引说明
公司标识使用公司简称或英文缩写，确保内部唯一性。示例： ABC 或 XX科技。
股东类型使用字母标注不同类型的股东，如“F”指法人股东，“Z”指自然人股东。
出资方式使用字母标注不同方式的出资，如“H”指货币出资，“S”指实物类的非货币财产出资。
年份填写签发证明书的四位数字年份。示例： 2024。
序列号当年内按签发顺序编排的唯一流水号，通常以3位数字表示。示例： 001

三、股权信息

（一）股东资格的取得
取得方式法律性质取得日期指引说明
公司设立原始取得公司成立之日（即营业执照签发之日）创始股东的资格取得方式，日期与公司成立日完全一致。
股权受让继受取得记载于股东名册之日注意股权转让合同生效后不会当然取得股东资格，而是从公司将受让人姓名或名称记载于股东名册时起取得股东资格，因此公司应在转让后及时修改股东名册并办理工商登记。
法院判决/仲裁继受取得法律文书生效之日以生效的判决书或裁决书为依据及时更新股东名册。
公司合并/分立继受取得合并协议生效之日/分立协议生效之日/相关法律文件约定之日依据合并或分立协议及相关股东会决议。
赠与继受取得记载于股东名册之日与股权转让类似，以股东名册记载为准。
股权继承继受取得被继承人（原股东）死亡之日继承人自该日起自动继承股东资格，公司应尽快更新股东名册，确认其资格。
股权承继继受取得记载于本公司股东名册之日适用于法人注销，其股权需要通过清算和分配程序转移给新的权利主体（受让人），取得方式不能写“继承”，而应根据具体情况填写为：股权转让（如协议出售给第三方）、 承继（如分配给其股东）或法院判决（如法院强制划转）。
（二）股东资格的丧失
丧失方式丧失日期指引说明
股权转让股东名册变更之日股权转让协议生效并不直接导致股东资格丧失，关键是公司将受让人记载于股东名册之日。公司应在此后及时办理工商变更登记，未登记不得对抗善意第三人。
股东失权失权通知发出之日依据新《公司法》，对未按期缴资的股东，公司经董事会决议可发出书面失权通知，通知发出之日即丧失未缴纳出资对应的股权。这是新公司法引入的重要制度。
自然人股东死亡死亡之日股东资格可依法继承。如公司章程规定禁止继承或继承人放弃继承，则股东资格在自然人股东死亡之日丧失。
法人股东终止终止之日当法人股东因解散、破产、被合并等原因终止时，其股东资格在终止之日丧失。
股权被强制执行股权过户至受让人名下之日人民法院强制执行股东股权时，原股东资格自相关登记机关将股权登记至受让人名下之日丧失。
公司解散/破产公司注销登记之日当公司法人资格消灭（如完成注销登记），所有股东的资格在公司注销登记之日统一丧失。
（三）股权类别
股权类别指引说明填写示例
普通股享有《公司法》规定的标准权利，即在表决权、分红权、剩余财产分配权等方面没有特殊安排。这是最常见和默认的股权类型。普通股
优先股/特别股股东在分红和/或剩余财产分配方面享有优先于普通股的权利。新《公司法》允许设立此类类别股。优先股 或 利润分配优先股
转让受限股该股权的转让受到公司章程的特别限制（例如，转让必须经其他股东过半数同意等）。新《公司法》允许设立此类类别股。转让受限股
特殊表决权股股东持有的每一股股权拥有多个表决权（例如“一股多票”），通常由创始人持有以保持控制权。新《公司法》允许股份有限公司发行此类股份。特殊表决权股 或 A类普通股
创始人股商业实践中对创始人持有的、可能附带特殊权利（如特殊表决权、转让限制）的股权的俗称。在法律上应归结为上述某种具体类别。创始人股（特殊表决权）
无表决权股股东享有分红权等财产性权利，但不享有表决权。无表决权普通股 或 优先股（无表决权）
（四）表决权比例
情况分类比例确定填写示例指引说明
默认比例按照股东的认缴出资比例行使表决权。此时，表决权比例 = 认缴出资比例。股东A认缴出资占注册资本40%，则填写：40%《公司法》规定：“股东会会议由股东按照出资比例行使表决权。” 此处的“出资比例”通常指认缴出资比例。
章程比例完全遵从公司章程的特别约定。这是灵活性最高的方式。• 不按出资比例：章程约定股东A虽出资30%，但享有51%表决权，则填写：51% • 一人一票：章程约定无论出资多少，每位股东一票，则按票数分配比例，如共5位股东，每人填写：20%《公司法》同时规定：“…但是，公司章程另有规定的除外。” 这是“同股不同权”的法律基础。
类别股份根据公司章程关于类别股（特别股）的规定确定。• 无表决权优先股：该股东的表决权比例为：0% • 超级表决权股：股东B持有“一股多票”的股份，其表决权比例需按章程计算后单独填写，如持股10%但表决权占40%，则填写：40%新《公司法》允许股份有限公司发行不同表决权类型的类别股。有限责任公司可通过章程实现类似安排。
股权代持/ 表决权委托以显名股东（名义股东）实际行使的表决权比例为准。隐名股东C委托显名股东D行使表决权，在D的名下，应合并计算其自身和C的表决权，如合计为35%，则在D的名下填写：35%。C不享有表决权。依据是有效的《股权代持协议》或《表决权委托协议》。公司通常只认可记载于股东名册的显名股东的权利。
（五）分红权比例
情况分类比例确定填写示例指引说明
默认比例股东按照实缴的出资比例分取红利。此时，分红权比例 = 实缴出资比例。公司注册资本100万，股东A实缴了30万，其分红权比例即为：30%《公司法》第210条规定：“股东按照实缴的出资比例分取红利；公司新增资本时，股东有权优先按照实缴的出资比例认缴出资。”
章程比例完全遵从公司章程的特别约定。这是最优先且最常用的例外规则。• 不按出资比例：章程可约定股东A虽只实缴20%，但可享有40%的分红权。 • 其他标准：章程可约定按认缴比例、一人一票或其他任何标准分配。《公司法》第210条同时规定：“…但是，全体股东约定或者公司章程规定不按照出资比例分取红利或者不按照出资比例优先认缴出资的除外。”
优先股根据公司章程关于类别股的规定确定。优先股股东通常在普通股股东之前，按约定比例获得固定股息。• 优先股：股东B持有“利润分配优先股”，其有权在普通股分红前，先按8%的年股息率分红。完成固定股息分配后，其是否参与剩余分红，需按章程规定。 • 普通股：在优先股分配完毕后，按章程约定比例分配剩余利润。新《公司法》引入了类别股制度。公司章程需明确规定优先股的分红顺序、定额或定率，以及是否参与二次分配。
